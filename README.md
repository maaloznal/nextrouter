# NextRouter

Лендинг роутеров Netis NX31 и N6v2 с OpenWrt и настроенным VPN.

## Запуск локально

Требуется Python 3:

```sh
python3 -m http.server 8080 --directory dist
```

Откройте http://localhost:8080 в браузере. Сборка и установка зависимостей не нужны.

## Структура

- `dist/index.html` — содержимое лендинга.
- `dist/style.css` — оформление, светлая и тёмная темы, адаптивная вёрстка.
- `dist/app.js` — интерактивная демонстрация приложения и переключатель темы.
- `dist/assets/` — изображения из предоставленных рекламных материалов и favicon.

## Возможности

- Адаптивные блоки для телефонов, планшетов и настольных экранов.
- Тёмная тема по умолчанию; выбранная тема сохраняется в браузере.
- Сравнение NX31 и N6v2 и предварительные цены.
- Демонстрация проверки пинга, выбора сервера каждые 30 секунд и ручной фиксации локации.
- Семейный VPN-тариф и Gemini Pro в подарок.
- Рассрочка и пробная неделя для Дагестана и Чеченской Республики.

Проверка серверов в демонстрации использует заранее заданные примеры и не подключается к реальному роутеру. Оплата, доставка и обработка заказов пока не подключены. Для шрифта Manrope используется Google Fonts; при отсутствии доступа применяется системный шрифт.
