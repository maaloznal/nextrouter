# NextRouter

Лендинг роутеров Netis NX31 и N6v2 с OpenWrt и настроенным VPN.

## Запуск локально

Требуется Python 3:

```sh
python3 -m http.server 8080
```

Откройте http://localhost:8080 в браузере. Сборка и установка зависимостей не нужны.

## Структура

- `index.html` — содержимое лендинга.
- `style.css` — оформление, светлая и тёмная темы, адаптивная вёрстка.
- `app.js` — интерактивная демонстрация приложения и переключатель темы.
- `assets/` — изображения из предоставленных рекламных материалов и favicon.

## Возможности

- Адаптивные блоки для телефонов, планшетов и настольных экранов.
- Тёмная тема по умолчанию; выбранная тема сохраняется в браузере.
- Сравнение NX31 и N6v2 и предварительные цены.
- Демонстрация проверки пинга, выбора сервера каждые 30 секунд и ручной фиксации локации.
- Семейный VPN-тариф и Gemini Pro в подарок.
- Рассрочка и пробная неделя для Дагестана и Чеченской Республики.

Проверка серверов в демонстрации использует заранее заданные примеры и не подключается к реальному роутеру. Оплата, доставка и обработка заказов пока не подключены. Для шрифта Manrope используется Google Fonts; при отсутствии доступа применяется системный шрифт.

## Публикация

GitHub Pages публикует сайт из корня ветки `main`. Файл `.nojekyll` отключает обработку Jekyll; HTML, CSS, JavaScript и изображения отдаются напрямую.

## Экраны и анимации

Отдельные правила оформления: до 359 px, 360–479 px, 480–767 px, 768–1023 px, 1024–1279 px, 1280–1599 px и от 1600 px. Между контрольными размерами используются гибкие сетки и размеры. Для горизонтального положения на невысоких экранах предусмотрена отдельная компоновка.

Включены мобильное меню, появление блоков при прокрутке, индикатор чтения, подсветка раздела и кнопка возврата наверх. Настройка `prefers-reduced-motion` отключает декоративные анимации.

## Изображение первого экрана

Уникальная иллюстрация создана встроенным генератором изображений. Это концептуальный образ роутера, а не точная фотография одной из моделей. WebP-файлы `assets/nextrouter-services-v3-640.webp`, `assets/nextrouter-services-v3-960.webp`, `assets/nextrouter-services-v3-1536.webp` позволяют браузеру выбрать размер по экрану.

Бриф генерации: премиальная иллюстрация NextRouter 3:2, тёмный фон, салатовые и голубые акценты, чёрный роутер с четырьмя антеннами и значки YouTube, Telegram, ChatGPT и Gemini. Единственный текст на изображении — NextRouter.

## Выбор модели

Цена и подарки показаны на первом экране. Помощник выбора выделяет NX31 при выборе скорости Wi‑Fi и N6v2 при выборе USB. На телефоне закреплена кнопка перехода к моделям; рядом с видимыми карточками она скрывается. Текст блоков центрирован, длинные абзацы ограничены по ширине для удобного чтения.

Рост конверсии не измерялся; аналитика, реальный канал заявок и A/B-тестирование пока не подключены.
